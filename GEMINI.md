# KalkuLab - Konteks Proyek

Aplikasi web kalkulator Kalkulus 1 (React + Vite + Tailwind CSS, JavaScript, bukan TypeScript).

## Aturan

- Jangan scaffold ulang dan jangan ubah konfigurasi Vite atau Tailwind: project sudah jalan. Baca package.json dulu untuk tahu versi yang dipakai, lalu ikuti cara konfigurasinya.
- Hanya JavaScript (.jsx/.js). Komponen fungsional + hooks.
- Styling hanya dengan utility class Tailwind. Tidak ada CSS kustom kecuali terpaksa.
- Logika matematika di folder src/engine (fungsi murni, tanpa React), UI di components dan modules.
- Library yang boleh ditambah: mathjs, nerdamer, katex, react-katex, recharts, vitest.
- Semua teks UI berbahasa Indonesia.
- Setiap fungsi engine harus ada test vitest.
- Kerjakan per tahap. Setelah satu tahap selesai, berhenti dan tunggu perintah berikutnya.
- Jangan hapus atau timpa file yang sudah ada tanpa menjelaskan alasannya dulu.
- Jangan menjalankan perintah di luar folder project ini, dan jangan pakai sudo atau rm di luar folder ini.
